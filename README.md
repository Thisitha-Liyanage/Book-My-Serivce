#  My Book My Service

A full-stack service booking platform where customers can book services (electricians, plumbers, technicians, etc.), service providers can manage and accept bookings, and admins can monitor the entire system.

The system includes **JWT authentication**, **role-based access (Admin, Customer, Service Provider)**, **email notifications**, and a **real-time booking workflow**.

---

##  Features

###  Customer
- Register & login (JWT authentication)
- Browse available services
- Filter services (category, location, availability)
- Book services easily
- View booking history
- Chat directly with service providers
- Rate completed services
- Receive email notifications for booking updates

---

###  Service Provider
- Register & login (JWT authentication)
- Add and manage services
- View incoming bookings
- Accept / Reject bookings via dashboard or email
- View booking history
- Track incomplete / pending bookings
- Receive email notifications for new bookings

---

###  Admin
- Manage all users (Customers & Service Providers)
- View all bookings in system
- Monitor services listed on platform
- Dashboard analytics:
  - Total customers
  - Total service providers
  - Total bookings
  - Total services
- Full system overview and control

---

##  Authentication & Security
- JWT (JSON Web Token) based authentication
- Role-based authorization (Admin / Customer / Provider)
- Secure API endpoints

---

##  Email Notification System
- Booking confirmation emails
- Booking acceptance / rejection alerts
- Service updates
- Provider notifications for new requests

---

##  Chat System
- Direct messaging between customer and service provider
- Real-time communication for booking coordination

---
